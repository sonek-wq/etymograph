# 英語語源ネットワーク辞書 EtymoGraph

英単語 ⇄ 語源パーツ ⇄ 印欧祖語（PIE）の繋がりを辿るビューアです。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | ビューア本体（表示ロジックのみ） |
| `etymo-data.json` | データ（PIE・パーツ・単語・出典） |
| `tools/` | データ追加用スクリプトの例と検証スクリプト（公開ページには不要） |
| `CLAUDE.md` | 編集する人向けの方針・手順メモ |

2つを同じフォルダに置いてください。

## 開き方

`index.html` をファイルとして直接開くと、ブラウザの制限で `etymo-data.json` を読み込めないことがあります。その場合は次のどちらかの方法を使ってください。

- フォルダで `python3 -m http.server` を実行し、`http://localhost:8000` を開く。
- 表示されるパネルに `etymo-data.json` をドロップする。

別のデータファイルを使うときは、`index.html?data=other.json` のように URL で指定します。

## 画面の使い方

- **カテゴリ一覧（最初の画面）:** 13の意味カテゴリ（`categories`）を輪状に表示します。上部の「カテゴリ一覧」ボタンでいつでも戻れます。カテゴリをクリックすると、その祖語と語根・接辞が開き、さらにクリックすると周囲の単語が開きます。輪の内側には、祖語を持たない語根・接辞を由来で分けた3つのまとまり（祖語未詳・語源不明・非印欧語、点線の枠）を置きます（下の「由来のまとまり」を参照）。
- **近傍ビュー:** 選んだノードの周囲 1〜3 ホップを描きます（「深さ」で切り替え）。
  - 中心以外で隣接が10を超えるノードは、超えた分を `+N` に折りたたみます。クリックすると展開します。
  - 一度に描くのは最大260ノードです。
- **検索:** 綴りのほか、日本語の意味でも検索できます（例：「見る」→ `*spek-`、「調べる」→ inspect）。索引パネルの絞り込みでは、パーツの意味から単語を引けます（例：「見る」→ inspect, vision …）。
- **未収録の語:** 検索で見つからないときは「まだ収録していません」と表示し、綴りの近い登録語の候補と Etymonline へのリンクを出します。
- **発音:** 単語の情報パネルで名前の横のスピーカーボタンを押すと、ブラウザの音声合成（Web Speech API、米国英語）で読み上げます。音声データは持たないため、声や発音は端末・ブラウザによって異なり、対応していないブラウザではボタンを出しません。
- **道探索:** 2つのノードの最短経路を、全データ上で探します。
  - 「接辞も経由」をオフにすると、接頭辞・接尾辞を通らず、語根と祖語だけで繋がる道を探します（出発・到着が接辞のときは除く）。設定はブラウザに保存します。
  - オフのままでは繋がらない組み合わせも多くあります。その場合は止まらずに、通る接辞の数ができるだけ少ない道（同数なら短い道）を表示し、検索欄の下と道のカードにその旨を出します。
  - どのパーツ・祖語を通っても繋がらない組み合わせ（祖語の分からない孤立した語根など）は、その旨を表示し、表示中の画面はそのままにします。
- **登録:** 祖語・語根・接辞・単語の情報パネルで、名前の横の ☆ を押すと登録できます（もう一度押すと解除。単語では発音ボタンの右）。登録はこのブラウザの localStorage に保存し、データの更新で消えたノードの登録も残しておきます（一覧には出しません）。
- **スマートフォン:** 画面幅 720px 以下では、図を見やすくするために配置を変えます（PC の表示は変わりません）。
  - 上部パネルは検索欄と操作ボタン（戻る・カテゴリ一覧・深さ・表示）だけにします。「戻る」「カテゴリ一覧」はアイコンだけにし、操作の説明文と状態の表示は省きます（検索で見つからないときの候補や道探索の結果は出します）。
  - 「検索」「道探索」の切り替えは出しません。道探索は、単語などのカードの「ここから道探索」「ここまでの道」から始めます。道探索の欄は「検索に戻る」で閉じます。道は上から下へジグザグに並べます。
  - 凡例は右下の「凡例」「索引」「登録」のボタンだけにし、「凡例」を押すと中身を開きます。
  - ノードの情報は画面下の小さめのカード（単語なら意味カテゴリまでが見える高さ。続きはスクロール）に出します。カードの上端（つまみ・見出し行）をタップすると、名前だけの小さな表示に切り替わり、図を広く見られます。もう一度タップすると戻ります。
  - 最初の画面のカテゴリは、輪ではなく2列に並べます。
  - 検索欄の右に「検索」ボタンを出します。キーボードの検索（Enter）キーのほか、日本語キーボードで変換中に確定した場合や、入力候補から語を選んだ場合も、そのまま検索します（指で操作する端末のみ）。
  - 図は、上部パネルと下のカードに隠れない範囲に収めます。
- **登録したノードの表示:** マップ上では、登録した単語は本体と文字を黄色（★と同じ #facc15）にします。祖語・語根・接辞は本体の色が種類を表すので変えず、名前を黄色にし、右上に★印を付けます（★は引いた状態でも一定の大きさで見えます）。登録したノードの文字は、ズームを引いても隠しません。
- **ノード名の表示切り替え:** 上部パネルの「表示」で、英+日（綴りと意味）・英（綴りだけ）・日（意味・和訳だけ）を切り替えられます。日本語のない語は英語で出します。設定はブラウザに保存します。カテゴリの表示は変わりません。
- **登録一覧:** 凡例の「索引」の右の「登録」から開きます。
  - 祖語・語根・接辞・単語のタブで絞り込めます。「すべて」では種類ごとにまとめて表示します。
  - 並べ替えは、新しい順・古い順・A→Z・Z→A・つながり順（直接つながるノードの数）から選べます。選んだ並べ替えは保存します。
  - 一覧の ★ で解除でき、直後なら「元に戻す」で取り消せます。索引で登録済みのノードには ★ が付きます。
- **ズームに応じた文字:** 引いた状態では祖語とカテゴリの文字を大きくし、語根・単語の文字を隠します。寄るにつれて語根、単語の順に文字が現れます。ホバー中・中心・道のノードは常に表示されます。
- **索引パネル:** 凡例の「索引」から開きます。祖語（カテゴリ別、「3系統そろう」絞り込み付き）、語根・接辞（系統で絞り込み）、単語（A〜Z）、学習順、同構成を一覧でき、クリックでグラフに移ります。
- **同語源の家族:** 単語の情報パネルに、同じ祖語から別の語根を通って生まれた単語を系統別に表示します（例：guest → hospital, hostile, hotel …）。単語 → 語根 → 祖語 → 別の語根 → 単語 の経路をたどります。接頭辞・接尾辞を経由すると無関係な語まで大量に入るため、経由するのは語根だけです（語根を持たない union などは接辞から出発します）。同じ語根を持つ単語は、上の「共有パーツで繋がる単語」に出すので除きます。
- **学習順（索引パネル）:** 少ない数の語根で多くの単語を説明できる順に語根を並べます（最大被覆問題の貪欲法）。単語は、構成する語根をすべて覚えたときに「説明できる」と数えます。各行に、その語根で新たに説明できる単語数と累計の割合を出します。「語根＋接辞」に切り替えると、接辞も覚える対象に含めます。
- **同構成（索引パネル）:** 構成パーツの組み合わせがまったく同じ単語のまとまりを、綴りの違いが大きい順に並べます。別の経路で英語に入った二重語（attitude / aptitude、debt / due など）の候補です。単語の情報パネルにも「同じ構成の語」として出ます。
- **言語系統:** 語根・接辞の外側に付く輪の色で、ラテン語系・ギリシア語系・ゲルマン語系・インド語派・イラン語派・ケルト語派・スラヴ語派・非印欧語を示します。語源不明の語根は輪が点線になります。祖語の情報パネルでは、派生パーツを系統ごとに並べます。
- **URL:** 表示状態は URL の `#` 以降に入るので、リンクで共有できます（例：`#c=mind`、`#f=word%3Ainspect`）。

## データ形式（etymo-data.json）

```json
{
  "version": 2,
  "categories": [ { "id": "nature", "name": "自然・天体", "color": "#60a5fa", "buck": "1 物理的世界", "longman": "A 生物, L 空間と時間" } ],
  "branches": [ { "id": "latin", "name": "ラテン語系", "short": "ラテン", "color": "#93c5fd" } ],
  "sources": {
    "etymonline": { "title": "Online Etymology Dictionary", "url": "https://www.etymonline.com/word/{entry}" },
    "watkins":    { "title": "Watkins, AHD of Indo-European Roots", "url": null }
  },
  "pie":   [ { "id": "*spek-", "gloss": "見る", "note": "…", "status": "verified",
               "src": [ { "id": "etymonline", "entry": "*spek-", "checked": "2026-10-24", "note": "…" } ] } ],
  "parts": [ { "id": "spect", "kind": "root", "gloss": "見る", "origin": "Lat. specere",
               "pie": ["*spek-"], "forms": ["spec", "spic"], "status": "verified", "src": [ … ] } ],
  "words": [ { "id": "inspect", "parts": ["in-", "spect"], "ja": "調べる", "literal": "中をのぞき込む" } ]
}
```

### 見出し表記のルール

| 種類 | 見出しの付け方 | 例 |
|---|---|---|
| 祖語（pie） | Etymonline の見出し表記。近年の表記は `alt`（別表記）に置く | `*kerd-`（別表記 `*ḱerd-`） |
| ラテン語系・ギリシア語系の語根・接辞 | 英単語に実際に現れる綴り。主な異形は「 / 」で2つまで併記し、残りは `forms` に置く | `cap / cept / ceive`、`con- / com- / co-` |
| ゲルマン語系の語根 | Etymonline が挙げる古英語・古ノルド語の辞書形 | `beran`、`hēafod` |

ラテン語系・ギリシア語系の見出しは、次の手順で決めています。

1. データ内の単語を照合し、各綴りが何語に現れるかを数える。
2. これまでの見出しが単語に現れるなら、それを先頭にする。現れないなら、最も多く現れる綴りを先頭にする。
3. 残りの綴りを多い順に2つまで併記する。先頭の綴りに文字を足しただけの形（scop に対する scope）は併記しない。

元のラテン語・ギリシア語の語（specere など）は `origin` に、出典の記載に合わせて書きます。単語の情報パネルの分解には、その単語の中で実際に使われている綴りを表示します（例：perfect = per- + fect）。綴りは各パーツの見出し・`forms` から、語の中で順に並び、互いに重ならない組み合わせを選びます（例：thesis = the + -sis、cohort = co- + hort）。語の中に見つからないパーツは見出しをそのまま表示します。そのため `forms` には、前後の接辞の文字を含む綴り（cohort に対する cohort、copious に対する cop など）を入れません。

### 由来のまとまり（祖語を持たない語根・接辞）

祖語の登録がない語根・接辞は、意味カテゴリではなく由来で次の3つにまとめます。カテゴリ一覧では輪の内側に点線の枠で表示します。

| まとまり | 判定基準 | 例 |
|---|---|---|
| 祖語未詳 | ラテン語・ギリシア語・ゲルマン祖語など、英語より前の形は分かるが印欧祖語まで遡れない | fīnis → final、ゲルマン祖語 *bainan → bone |
| 語源不明 | 英語（古英語・中英語）の形より前に遡れず、借用元も分からない（`etym: "unknown"`） | boy, girl, dog, bird, fun, cut, fit, flag, struggle |
| 非印欧語 | 非印欧語に由来する（`etym: "nonie"`） | coffee, cotton, cat, elephant, card, belt, tea, lion, zero |

言語ごとの中心ノード（「アラビア語」など）は作りません。作ると、無関係な語（coffee と zero など）がそこで繋がり、同語源の家族や道探索の意味が崩れるためです。同じ源を持つ語は、共通の語根ノード（qahwah → coffee, cafe, caffeine）で繋がります。

### categories（意味カテゴリ）

祖語を元の意味（Etymonline の語釈）で分類するためのカテゴリです。Buck『A Dictionary of Selected Synonyms in the Principal Indo-European Languages』（1949）の22の意味分野を土台に、Longman Lexicon of Contemporary English（1981）の14の大分類と照合してまとめています。

| 項目 | 内容 |
|---|---|
| `id` | 一意なキー（pie の `category` から参照） |
| `name` | 表示名 |
| `color` | カテゴリ一覧での色 |
| `buck` / `longman` | 対応する Buck の分野番号、Longman Lexicon の大分類 |

「動物」は Buck の分野 3（Animals）、Longman の A（生物）に当たります。祖語が増えたため、「自然・天体」から独立させました。

「姿勢・存在」は、立つ・座る・横たわるに加えて「ある・いる」（*es-、*bheue-）を含みます。多くの言語で「ある」が「立つ・座る・横たわる」と近い語で表されることによります。

分類のルールは次の2つです。

- 派生語ではなく、祖語の元の意味で分ける。
- 祖語1つにカテゴリ1つ。2つの意味を持つ祖語は、データ内の派生語の大半が属する側に入れる。

パーツは帰属する祖語のカテゴリを引き継ぎ、単語は語根のカテゴリを引き継ぎます。

### branches（言語系統）

| 項目 | 内容 |
|---|---|
| `id` | 一意なキー（parts の `branch` から参照）：`latin` / `greek` / `germanic` / `indic` / `iranian` / `celtic` / `slavic` / `nonie`（非印欧語） |
| `name` / `short` | 表示名 / 短い表示名 |
| `color` | 語根・接辞の外側の輪の色 |

### pie（印欧祖語）

| 項目 | 内容 |
|---|---|
| `id` | 一意なキー。Etymonline の見出し表記に合わせ、同綴りの別祖語は Etymonline の番号で `*per-(1)` / `*per-(2)` のように分ける |
|  | 接辞の起源となる祖語の接尾辞（`*-nt-`・`*-to-`・`*-(i)ko-`・`*-ita`・`*-tro-`）も祖語として収録し、同じ起源の接辞（例：`-ing` と `-ent`）をつなぐ。カテゴリは `relation` |
| `alt` | 別表記（近年の表記、例：`*kerd-` に対する `*ḱerd-`）。情報パネルに表示され、検索でも引ける（任意） |
| `label` | 表示名（省略時は `id`） |
| `gloss` | 意味 |
| `note` | 補足（省略可） |
| `category` | categories の `id` |
| `status` | 照合状態（下表） |
| `src` | 出典（下表） |

### parts（語根・接辞）

| 項目 | 内容 |
|---|---|
| `id` / `label` | pie と同じ。例：`{"id":"in-(neg)","label":"in-"}` |
| `kind` | `root` / `prefix` / `suffix` |
| `pie` | 帰属する祖語 `id` の配列。不明なら `[]`、複数も可（例：cred） |
| `forms` | 異形・綴りの揺れ。検索でもヒットする |
| `origin` | 由来（例：`Lat. specere`） |
| `branch` | branches の `id`。英語に入った経路の系統（フランス語経由はラテン語系）。非印欧語に由来する語根は経路によらず `nonie` とし、経路は `origin` に書く |
| `etym` | 由来の区分（任意）：`unknown`（語源不明）/ `nonie`（非印欧語）。どちらも `pie` は `[]` にする。省略時は通常（祖語ありまたは祖語未詳） |
| `note` | 補足（省略可） |
| `status` / `src` | pie と同じ |

### words（単語）

| 項目 | 内容 |
|---|---|
| `id` | 単語。綴りが同じで語源が違う語は、2つ目以降に `bear(2)` のように番号を付ける（画面では bear² と表示。検索は `bear(2)` または `bear2`） |
| `parts` | パーツの `id` を語の中の順に並べる |
| `ja` | 短い和訳（任意）。多義語は語源に対応する意味を選ぶ |
| `literal` | 直訳（任意）。パーツの意味から意味の流れが分かる短い句（例：comprehension「すっかりつかむこと」）。英語本来語の1パーツ語は、元の形と元の意味を書く（例：know「古英語 cnāwan『知る』から」） |

`parts` の付け方は次のとおりです。

- 複合語は、すべての構成要素を並べる（例：forehead = fore + head、hippopotamus = hippo + potam）。
- 短縮語・混成語は、元になった語の構成要素をすべて並べる。語の中に現れない要素も含める（例：internet = inter- + net + work、aerosol = aero + sol（solution）+ -ion、phone = tele- + phon）。
- 印欧祖語まで遡れなくても、ラテン語・ギリシア語・ゲルマン語・インド語・イラン語などで元の語がはっきりしている要素は、祖語なし（`pie: []`）の語根として入れる（例：fīnis → final, finish, define …、causa → cause, accuse, excuse）。祖語の候補があれば `note` に書く。地図では「祖語未詳」にまとまる。
- 英語（古英語・中英語）の形より前に遡れず、借用元も分からない要素は「語源不明」（`etym: "unknown"`）の語根として入れる（例：boy → boy, cowboy, schoolboy、dog → dog, hotdog）。`origin` に最古の形、`note` に Etymonline が挙げる説を書く。
- 非印欧語に由来する要素は「非印欧語」（`etym: "nonie"`、`branch: "nonie"`）の語根として入れる（例：アラビア語 qahwah → coffee, cafe, caffeine、ギリシア語 leōn → lion, chameleon、Beekes が先ギリシア語とする thea → theater, theory）。Etymonline が非印欧語起源を主な説（"probably" を含む）として挙げるものが対象。一説にとどまるもの（autumn・form・person のエトルリア語説など）や、途中でサンスクリット語・ペルシア語を経て先が不確かなもの（candy・orange・lemon など）は祖語未詳のまま `note` に書く。
- 複合語は通常どおりすべての要素を並べる（cowboy = cow + boy、coffeehouse = coffee + house）。語源不明・非印欧語の要素を含む単語は、情報パネルにその旨を表示する。

単語同士のリンクは書きません。グラフは必ずパーツを媒介します。

単語の情報パネルには、和訳、パーツの意味による分解（例：in-（中に）+ spect（見る））、直訳を表示します。分解は各パーツの `gloss` から自動で作るので、`ja` と `literal` が空でも表示は崩れません。

### 照合状態（status）と出典（src）

| status | 画面での印 | 意味 |
|---|---|---|
| `verified` | なし | `src` の出典と照合済み（出典は情報パネルに表示） |
| `review` | ? | 出典と食い違いがあり要確認（表記の違いなど） |
| `unverified`（省略時） | なし | 未照合 |

出典は主に Etymonline（`etymonline`）です。Etymonline が祖語を示していない語根の一部は、American Heritage Dictionary の印欧語根付録（`ahd`、Calvert Watkins）で補っています。Etymonline で確認できない語は、Claude（AI）の知識で補っています。その場合は出典を `knowledge`「Claude（AI）の知識による補足（Etymonline 未照合）」とし、`status` は `unverified` にしています。

`src` の各要素は次の項目を持ちます。

| 項目 | 内容 |
|---|---|
| `id` | `sources` に登録した出典キー |
| `entry` | 見出し語。`url` の `{entry}` に入る |
| `anchor` | ページ内の位置（`url` の `{anchor}` に入る。AHD の IR 番号など。省略時は `entry`） |
| `checked` | 照合日 |
| `note` | 照合メモ（省略可） |

参照切れ、重複 `id`、未定義の出典・カテゴリ・系統、カテゴリ未設定の祖語、不正な `status` は、凡例の下に「⚠ データ警告」として表示されます。
